# brenuuuu.github.io

Meu site portfólio, publicado em **https://brenuuuu.github.io**.

Feito com HTML, CSS e JavaScript puros, sem frameworks: layout responsivo, acessível pelo teclado e respeitando a preferência de "reduzir movimento" do sistema.

Para editar, basta mudar o `index.html` e fazer commit. O GitHub Pages atualiza o site sozinho.
